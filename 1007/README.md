# 6장. 자바스크립트 언어

## 강의 목표
1. 자바스크립트 언어의 요소와 구조를 이해한다.
2. 자바스크립트 코드를 웹 페이지에 삽입하는 방법을 안다.
3. 자바스크립트로 브라우저에 출력하고 사용자 입력 받는 방법을 안다.
4. 자바스크립트에서 다루는 데이터 타입과 변수에 대해 이해한다.
5. 자바스크립트의 연산자의 종류를 알고 사용할 수 있다.
6. 자바스크립트의 조건문의 종류를 알고 사용할 수 있다.
7. 자바스크립트의 반복문의 종류를 알고 사용할 수 있다.
8. 자바스크립트 함수를 작성할 수 있다.
9. 사용자에게 제공되는 `eval()`, `parseInt()` 등 자바스크립트 함수를 활용할 수 있다.

## 1. 자바스크립트 언어
- 1995년 넷스케이프 개발, Netscape Navigator 2.0 브라우저에 최초 탑재
- 웹 프로그래밍 개념 창시
- 특징
  - HTML 문서에 내장되는 조각 소스 코드
  - 스크립트 언어: 인터프리터 실행, 컴파일 필요 없음
  - 단순함: C언어 구조 차용, 배우기 쉬움

### 웹 페이지에서 자바스크립트의 역할
- 사용자의 입력 및 계산
  - 마우스와 키보드 입력은 오직 자바스크립트로만 가능
- 웹 페이지 내용 및 모양의 동적 제어
  - HTML 태그의 속성, 콘텐츠, CSS 프로퍼티 값 동적 변경
- 브라우저 제어
  - 윈도우 크기와 모양 제어, 새 윈도우 열기/닫기, 다른 사이트 접속, 히스토리 제어
- 웹 서버와의 통신
- 웹 애플리케이션 작성
  - 캔버스 그래픽, 로컬/세션 스토리지 저장, 위치정보서비스 등

## 2. 자바스크립트 코드의 위치
- 작성 가능한 위치 4가지
  1. HTML 태그의 이벤트 리스너 속성
  2. `<script></script>` 태그
  3. 자바스크립트 파일
  4. URL 부분

## 3. 자바스크립트로 HTML 콘텐츠 출력
- `document.write()`: HTML 콘텐츠를 웹 페이지에 바로 출력
- `document.writeln()`: 텍스트 뒤에 `\n`을 붙여 출력
  - `\n`은 빈칸 하나일 뿐, 다음 줄로 넘어가지 않음

### 예제 6-5 document.write()로 웹 페이지에 HTML 콘텐츠 출력

## 4. 자바스크립트 다이얼로그
### 프롬프트 다이얼로그
- `prompt("메시지", "디폴트 입력값")`: 문자열을 입력받아 리턴
  - 취소 버튼이나 닫기: `null`
  - 입력 없이 확인: `""`

### 확인 다이얼로그
- `confirm("메시지")`: 확인/취소 버튼 다이얼로그
  - 확인: `true`, 취소나 닫기: `false`

### 경고 다이얼로그
- `alert("메시지")`: 메시지와 확인 버튼 출력

## 5. 식별자와 문장
### 식별자
- 변수, 상수(리터럴), 함수의 이름
- 첫 문자: 알파벳, `_`, `$`만 가능
- 두 번째부터: 알파벳, `_`, 0-9, `$`
- 대소문자 구분 (`myHome`과 `myhome`은 다름)
- 예약어(`false`, `for`, `if`, `null` 등) 사용 불가

### 문장
- 문장 구분은 세미콜론(`;`)
- 한 줄에 한 문장이면 세미콜론 생략 가능
- 한 줄에 여러 문장이면 문장마다 세미콜론 필요
- 주석: `// 한 줄`, `/* 여러 줄 */`

## 6. 데이터 타입
- 숫자: 정수, 실수 (`42`, `3.14`)
- 논리: `true`, `false`
- 문자열: `'좋은 세상'`, `"a"`, `"365"`
- 객체 레퍼런스: 객체를 가리킴 (C의 포인터와 비슷)
- `null`: 값이 없음을 표시하는 특수 키워드
- 문자 타입은 없고 문자열로 표현

## 7. 변수와 상수
### 변수 선언
- 3가지 방법 모두 사용
  - `var`: 처음부터 있던 방법
  - `let`: `var`의 문제점을 해소하려고 2015년 ES6에서 추가
  - `const`: ES6에서 추가, 상수 선언 (한 번 저장하면 변경 불가)
- `var`/`let` 없이 `age = 21;`처럼 쓰면 변수가 선언되고 초기화됨
- 변수 타입은 없음 (`int score;`는 오류)
- 저장 값에 제약 없음 (숫자, 문자열 모두 가능)

### 변수의 사용 범위와 생명
| 구분 | 선언 | 사용 범위 | 생명 |
|---|---|---|---|
| 전역 변수 | 함수 밖, 또는 `var`/`let` 없이 아무 곳 | 프로그램 전역 | 프로그램 시작~종료 |
| 지역 변수 | 함수 내에 `let` | 선언된 함수 내 | 함수 실행~종료 |
| 블록 변수 | `if`, `while`, `for` 등 블록 내에 `let` | 선언된 블록 내 | 블록 시작~끝 |

### `this`로 전역변수 접근
- 지역 변수와 전역 변수 이름이 같을 때 `this.전역변수`로 전역 변수에 접근
- `let`으로 선언한 전역 변수는 `this`로 접근 불가

### 예제 6-6 지역 변수와 전역 변수, 블록 변수
- 함수 안의 지역 변수 `y`, 블록 변수 `b`, 전역 변수 `x`, `z`의 사용 범위 확인

### `let`의 특징
- 변수 재선언 실수를 줄이려고 도입
- 같은 이름 재선언 불가 (`var`는 가능)
- 변수 사용 범위를 블록 내로 제한
- `var`보다 `let` 사용 권고

### 상수
- `const MAX = 10;`
- 값 수정 불가, 재선언 불가
- 블록 범위에서만 사용

## 9. 식과 연산
### 산술 연산자
- `+`, `-`, `*`, `/`, `%`
- 나눗셈 결과는 항상 실수 (`32/10`은 3.2)

### 예제 6-8 산술 연산
- `100 + x*2/4 - 3`, `x/10`, `x%2` 계산 결과 출력

### 증감 연산자
- `++`, `--`
- 전위(`b = ++a`): 증가 후 값 사용 (a=2, b=2)
- 후위(`b = a++`): 증가 전 값 사용 (a=2, b=1)

### 대입 연산자
- 오른쪽 식의 결과를 왼쪽 변수에 대입
- `a += b`는 `a = a + b`

### 예제 6-9 대입 연산
- `+=`, `*=`, `%=` 실행 전후 값 출력

### 비교 연산자
- 결과는 `true` 또는 `false`
- `==`, `!=`, `>=`, `>`, `<=`, `<`

### 예제 6-10 비교 연산
- x=13, y=7로 비교 연산 6가지 결과 출력

### 논리 연산자
- AND(`&&`), OR(`||`), NOT(`!`)

### 예제 6-11 논리 연산
- `true`/`false`와 조건식에 논리 연산 적용

### 조건 연산자
- `condition ? expT : expF`
- 조건이 참이면 `expT`, 거짓이면 `expF`의 값

### 예제 6-12 조건 연산
- 두 수의 차이를 `(a>b)?(a-b):(b-a)`로 구함

### 비트 연산
- 비트 논리 연산: `&`, `|`, `^`, `~`
- 비트 시프트 연산: `<<`, `>>`, `>>>`
  - 왼쪽으로 1비트 이동은 곱하기 2 효과
  - 오른쪽으로 1비트 이동은 나누기 2 효과

### 예제 6-13 비트 연산
- `digit8()` 함수로 수를 8비트 2진수로 바꿔 비트 연산 결과 출력

### 문자열 연산자
- 연결: `+`, `+=`
  - `"abc" + 23`은 `"abc23"`, `23 + "35"`는 `"2335"`, `23 + 35`는 58
  - 계산 순서에 유의: `23 + 35 + "abc"`는 `"58abc"`, `"abc" + 23 + 35`는 `"abc2335"`
- 비교: `==`, `!=`, `>`, `<`, `>=`, `<=`를 문자열에도 사용, 사전 순으로 비교

### 예제 6-14 문자열 연산
- 숫자와 문자열을 `+`로 섞을 때 결과와 문자열 비교 결과 출력

## 10. 조건문
### if, if-else
```
if(조건식) {
  ...
}
else if(조건식2) {
  ...
}
else {
  ...
}
```

### switch 문
- 값에 따라 서로 다른 코드를 실행할 때 사용
- `case` 값은 `const` 상수나 리터럴만 가능 (변수, 식은 불가)
  - `case 2+3`은 가능 (먼저 5로 계산됨)
- `break`를 만날 때까지 아래로 계속 실행
- 여러 `case`에 같은 코드를 실행하려면 `break`를 일부러 생략

### 예제 6-16 switch 문 사용

## 12. 함수
- 목적을 가지고 작성된 코드 블록
- 데이터를 전달받아 처리한 후 결과를 돌려줌

### 함수의 구성과 호출
```
function 함수이름(arg1, arg2, ..., argn) {
  ...프로그램 코드...
  return 결과;
}
```
- 호출: `let n = adder(10, 20);` → 함수 코드를 실행하고 값을 돌려받음

### 예제 6-22 adder() 함수 작성 및 호출
- 두 수를 더해 리턴하는 `adder()` 정의 후 호출

### 자바스크립트 전역 함수
- `eval()`: 문자열 식을 계산 (`eval("2*3+4*6")`은 30)
- `parseInt()`: 문자열을 정수로 변환
  - `parseInt("32")`는 32
  - `parseInt("0x32")`는 16진수로 해석해 50
  - `parseInt("hello")`는 `NaN`
- `isNaN()`: 숫자가 아니면 `true`
  - `isNaN(32)`, `isNaN("32")`는 `false`
  - `isNaN("hello")`는 `true`
