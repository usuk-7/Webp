## 교과목 개요

HTML, CSS, JavaScript를 중심으로 웹 프론트엔드 개발의 기본 개념과 기술을 학습한다. 웹의 구조 설계(HTML), 시각적 표현(CSS), 동적 기능 구현(JavaScript)을 체계적으로 익히고, 사용자와 상호작용하는 웹 페이지를 직접 구현해보며 실습 중심으로 진행한다. 프로그래밍 초급자도 이해할 수 있도록 구성하며, 프로젝트 기반 학습을 통해 실무 역량을 강화한다.

## 교과목 목표

- HTML5로 웹 문서의 구조를 설계할 수 있다.
- CSS3로 웹 페이지를 꾸미고 레이아웃을 구성할 수 있다.
- JavaScript로 동적 기능과 사용자 상호작용을 구현할 수 있다.
