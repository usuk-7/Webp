# 2장. HTML5 기본 문서 만들기

## 강의 목표
1. 웹 페이지를 만드는 기초적인 HTML 태그들을 안다.
2. HTML5 기본 문서를 만들 수 있다.
3. 웹 페이지에 이미지, 표, 하이퍼링크를 삽입할 수 있다.
4. 인라인 프레임을 사용하여 웹 페이지에 다른 웹 페이지를 내장할 수 있다.
5. 오디오 비디오를 웹 페이지에 삽입할 수 있다.

## 1. HTML 페이지 기본

### HTML5 페이지 기본 구조
```
<!DOCTYPE html>
<!--이 부분은 주석문입니다. 웹 브라우저는 주석을 화면에 출력하지 않습니다.-->
<html>
  <head>
    문서제목, 자바스크립트 코드, CSS 스타일 정의, 메타데이터정의
  </head>
  <body>
    문서의 본문 텍스트, 이미지, 테이블, 자바스크립트 코드, 동영상 등
  </body>
</html>
```

### HTML5 페이지의 필수 태그
- `<!DOCTYPE html>` - HTML5 문서임을 알리는 지시어
- `<html>`, `<head>`, `<title>`, `<body>` 태그

### HTML 태그의 특징
- 태그 구성: `<img src="heart.jpg" width="100" height="50" alt="사랑합니다">` — 태그이름 + 속성(attribute)="속성값"
- 시작태그와 종료태그가 모두 있는 경우: `<html>...</html>`, `<title>문서의 제목입니다</title>`
- 시작 태그만 있는 경우: `<br>`
- 태그와 속성은 대소문자 구분 없음
- 속성 값에 불필요한 공백 문자는 HTML5 표준에 어긋남

## 3. 문자, 기호, 심볼 입력

- HTML5의 문자: 유니코드 문자셋, UTF-8 코드 체계
- 예약어나 키보드로 입력이 어려운 기호는 엔티티(`&엔터티;`) 또는 코드(`&#코드값;`)로 표현

| 문자 | 엔터티표현 | 코드표현 |
|---|---|---|
| " | `&quot;` | `&#34;` |
| ' | `&apos;` | `&#39;` |
| < | `&lt;` | `&#60;` |
| > | `&gt;` | `&#62;` |
| & | `&amp;` | `&#38;` |
| 빈칸 | `&nbsp;` | `&#160;` |

### 예제 2-9 텍스트 꾸미기

- `<small>` 한 단계 작은 문자, `<del>` 삭제, `<ins>` 추가
- `<sup>` 윗첨자, `<sub>` 아래첨자, `<mark>` 하이라이팅

## 4. 블록 태그와 인라인 태그

- 블록 태그: 항상 새 라인에서 시작, 한 라인 독점 사용 — 예: `<p>`, `<h1>`, `<div>`, `<ul>` (가장 많이 쓰는 것은 `<div>`)
- 인라인 태그: 블록 속에 삽입되어 블록의 일부로 출력 — 예: `<strong>`, `<a>`, `<img>`, `<span>` (가장 많이 쓰는 것은 `<span>`)

### 예제 2-10 `<div>` 블록과 `<span>` 인라인
`style="background-color:skyblue"` 같은 CSS3 스타일을 `<div>`나 `<span>`에 인라인으로 적용 가능

## 5. 메타 데이터 삽입

- 메타 데이터: 데이터를 설명하는 데이터 (예: 사진의 촬영 장소·시간, 이미지의 폭·높이 등)
- HTML 페이지의 메타 데이터를 담는 태그: `<base>`, `<link>`, `<script>`, `<style>`, `<title>`, `<meta>` — `<head>` 태그 안에 작성 (`<script>`는 `<body>` 내에도 작성 가능)
- `<base>`: 웹 페이지들의 기본 URL과 출력될 윈도우 지정 (base 지정 후에는 상대경로만 써도 됨)
- `<link>`: 외부 자원 연결 (예: `<link type="text/css" rel="stylesheet" href="mystyle.css">`)
- `<meta>`: 저작자(`author`), 페이지 설명(`description`), 키워드(`keywords`), 문자 인코딩(`charset="utf-8"`) 등 지정

## 6. 이미지 삽입

`<img>` 태그의 `src` 속성에 이미지 파일 주소 지정 (BMP, GIF, PNG, JPG, animated-GIF 가능)

```
<img src="이미지 파일의 URL" alt="문자열" width="이미지 폭" height="이미지 높이">
```
- `src`: 필수 속성. `alt`: 이미지가 안 보일 때 대신 출력할 문자열, 필수 속성
- `width`, `height` 생략 시 원본 크기로 출력
- 이미지 파일은 보통 HTML 파일 경로 아래 media 폴더를 만들어 둠

## 7. 리스트 만들기

3가지 종류
- 순서 있는 리스트(ordered list) `<ol>...</ol>`
- 순서 없는 리스트(unordered list) `<ul>...</ul>`
- 정의 리스트(definition list) `<dl>...</dl>`

리스트 아이템은 `<li>...</li>` (`</li>` 생략 가능)

- `<ol type="1"|"A"|"a"|"I"|"i" start="값">` — type은 마커 종류(숫자/대문자/소문자/로마자), start는 마커 시작값(숫자에만 적용)
- type, start 속성 대신 CSS3 스타일 사용을 권장

## 8. 표 만들기, `<table>`

표 구성 태그
- `<table>`: 표 전체를 담는 컨테이너
- `<caption>`: 표 제목 (`<table>` 내에 반드시 첫 번째로 삽입)
- `<thead>`: 헤딩 셀 그룹, `<tfoot>`: 바닥 셀 그룹, `<tbody>`: 데이터 셀 그룹 (각각 여러 `<tr>` 포함 가능)
- `<tr>`: 행 (여러 `<td>`, `<th>` 포함)
- `<th>`: 열 제목(헤딩) 셀, `<td>`: 데이터 셀

```
<table>
  <caption>표제목</caption>
  <thead> ... </thead>
  <tfoot> ... </tfoot>
  <tbody> ... </tbody>
</table>
```

## 9. 하이퍼링크 만들기, `<a>`

- 하이퍼링크: 다른 HTML 페이지(같은 사이트 또는 다른 사이트)로의 연결 고리. 텍스트나 이미지로 작성
- 항해(navigation): 하이퍼링크를 따라 다른 웹 페이지를 방문하는 것

```
<a href="URL"|"URL#앵커이름"|"#앵커이름" target="윈도우이름">텍스트 혹은 이미지</a>
```
- `href`: 이동할 HTML 페이지의 URL 혹은 페이지 내 앵커 이름
- `target`: 링크에 연결된 페이지가 출력될 윈도우 이름

### 예제 2-18 하이퍼링크 만들기
텍스트 링크, 이미지 링크(`<a>` 안에 `<img>`), 다른 페이지 이동 등

### 하이퍼링크 텍스트의 색
- standard link(첫 방문): 밑줄과 함께 blue
- visited link(방문 후): purple
- active link(누르는 동안): red
- CSS3로 색 변경 가능

### 예제 2-19 링크의 target 속성 활용
`_blank`(새 윈도우), `_self`(현재 윈도우), `_parent`(부모 윈도우), `_top`(최상위 브라우저 윈도우)

### `<a>` 태그의 id 속성으로 앵커 만들기
- 앵커: HTML 페이지 내 특정 위치. `<a id="앵커이름">` 또는 `<h3 id="앵커이름">`으로 생성
- `<a href="#앵커이름">`으로 해당 위치로 이동하는 링크 작성

## 10. 인라인 프레임, `<iframe>`

HTML 페이지 내에 다른 HTML 페이지를 삽입

```
<iframe src="URL" srcdoc="HTML 문서 텍스트" name="윈도우 이름"
        width="프레임의 폭" height="프레임의 높이">
  iframe 태그를 지원하지 않는 브라우저에 대신 출력되는 텍스트
</iframe>
```
- `src`: 출력할 웹 페이지의 URL, `srcdoc`: 직접 HTML로 작성한 내용 출력 (srcdoc이 있으면 src는 무시됨)
- `name`: 프레임 윈도우 이름, 다른 페이지에서 target 값으로 사용
- `width`, `height`: 프레임 크기 (디폴트 300x150)

### 브라우저 윈도우와 인라인 프레임의 계층 관계

## 11. 미디어 삽입

HTML5는 `<audio>`, `<video>` 태그로 미디어 삽입을 표준화 (플러그인 불필요). 비표준 미디어(플래시 등)는 `<embed>`, `<object>` 태그 사용

### `<video>` 태그
```
<video src="비디오 파일의 URL" width="폭" height="높이" controls autoplay muted loop>
  이 태그를 지원하지 않는 브라우저가 출력하는 메시지
</video>
```
- `controls`: 재생/중단/음소거 등 제어 버튼 출력
- `autoplay`: 로딩 즉시 재생, `loop`: 반복 재생, `muted`: 오디오 끄기
- 비디오 소스를 `<source src="..." type="비디오의 마임타입">`으로 별도 지정 가능 (MP4=video/mp4, WebM=video/webm, Ogg=video/ogg)
