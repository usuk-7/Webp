# 0902 실습과제 — HTML5/CSS 오류 찾기

## 문제 1

### 찾은 오류
- HTML ① : `<DOCTYPE html>` → `!` 빠짐. `<!DOCTYPE html>`로 수정.
- HTML ② : `<style>` 블록이 `</style>`로 닫히지 않고 바로 `</head>`가 옴. `</style>` 추가.
- CSS ① : `span { color = blue; ... }` → `=`는 CSS 문법 아님. `color : blue`로 수정.

### 수정된 코드

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>오류를 찾으세요</title>
<style>
    h3 { text-align : center; color : darkred; }
    span { color : blue; font-size : 20px; }
</style>
</head>
<body>
<h3>Elvis Presley</h3>
He was an American singer and actor. In November 1956,
he is often referred to as "<span>the King of Rock and Roll</span>".
</body>
</html>
```

## 문제 2

### 찾은 오류
- HTML ① : `<html>` 다음에 `<body>`가 옴 → `<head>`가 되어야 함 (meta, title, style은 head 안에 들어가야 하고, 뒤에 `</head>`와 두 번째 `<body>`가 있어 구조가 꼬임).
- HTML ② : `<h3>Elvis Presley</h>` → 닫는 태그가 `</h>`로 잘못됨. `</h3>`로 수정.
- CSS ① : `h3 { text-align : center color : darkred; }` → `center` 뒤에 세미콜론(`;`) 빠짐.

### 수정된 코드

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>오류를 찾으세요</title>
<style>
    h3 { text-align : center; color : darkred; }
    span {color : blue; font-size : 20px; }
</style>
</head>
<body>
<h3>Elvis Presley</h3>
He was an American singer and actor. In November 1956,
he is often referred to as "<span>the King of Rock and Roll</span>".
</body>
</html>
```
